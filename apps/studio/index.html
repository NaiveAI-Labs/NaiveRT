Queue wait is reported by the runtime. TTFT after queue subtracts that wait from the browser’s total time to first content; network and gateway delays remain included. Older servers show total TTFT and an unknown queue wait.

Curve: received tok/s over a rolling ~1 s window, sampled every 200 ms. Peak is the highest sampled rate. Prefill and finalization are excluded.

Device TPS uses server execution intervals. Streamed TPS = generated tokens received after the first content batch ÷ time from first to last content batch. Both exclude prefill and finalization; TTFT and total elapsed are separate. Streamed TPS requires server token-progress metadata; text length and event counts are never used as token counts.
